## Reproduce

```bash
pip install -r requirements.txt                      # Python 3.14.8; exact versions in ENVIRONMENT.txt
# download EH2005.rar from INE (DATASET.md §1), extract, and put the 4 files in data/bolivia/
sha256sum -c SHA256SUMS                              # must print OK for all 4 files
./run_all.sh 2>&1 | tee results/run_all_log.txt     # frozen pipeline: results/{audit,Bolivia,sensitivity,dataset}
./run_audits.sh                                      # results/{a8_audit,cv_qr,table_a2}; about 1.5–2 h
python3 audit_2026-11-04_step5_threshold_scan/scripts/threshold_scan.py   # + family_ranking.py, plot_threshold_scan.py (data of Figure 1)
python3 audit_2026-11-04_step5_quantile_path/scripts/quantile_path.py     # + plot_quantile_path.py   (data of Figure 2; needs cv_qr)
python3 final_manuscript/figures/make_journal_figures.py   # Figures 1–2 at journal print size
python3 final_manuscript/tables/make_tables.py       # paper tables
python3 final_manuscript/build_docs.py                # Manuscript + Online Appendix (DOCX; PDF via LibreOffice)
python3 final_manuscript/extract_numbers.py && python3 final_manuscript/check_numbers.py   # number check
```

The CV-QR vs QRF pilot is reproduced by `audit_2026-11-04_repeated_split/scripts/repeated_split_cvqr_vs_qrf.py`. The exact commands are in that folder's `logs/COMMANDS.log`.

**Determinism:** re-running `run_all.sh` on 2026-11-06 reproduced every aggregate result file byte-for-byte (`CODE_REVIEW.md`).

## Data and licence notes

* The **raw survey data are not included**: INE Bolivia microdata, with no open redistribution licence found. Household-level predictions and plots are also excluded; `train_models.py` regenerates them locally.
* The R source files in `audit_2026-11-04_repeated_split/evidence/r_source/` are excerpts of the GPL-licensed CRAN packages `randomForest` 4.6-12 and `quantregForest` 1.3-5. They are included unchanged as audit evidence, with SHA-256 hashes.
* **Code licence:** MIT (`LICENSE`); it does not cover the INE data or the GPL R excerpts. Citation metadata: `CITATION.cff`.
