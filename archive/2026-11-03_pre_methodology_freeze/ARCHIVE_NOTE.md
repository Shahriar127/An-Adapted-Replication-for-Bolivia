# Archive: state before the methodology freeze (2026-11-03)

This snapshot was taken before any change made to align with the published reference (McBride & Nichols 2018, WBER 32(3):531–550, doi:10.1093/wber/lhw056).

Known issue in these results: PA and BPAC were computed with the denominator TP+FP, taken from the 2015 working paper's Table 2. The published Table 2 (p. 534) uses TP+FN. TA, UC and LE are unaffected.

Do not cite these numbers. To check that the archive is intact, run `sha256sum -c MANIFEST.sha256`.

Note: the redistributable tarball leaves out household-level files (predictions.csv) and PNGs from this archive, so outside the original machine `sha256sum -c` reports those files as missing.
